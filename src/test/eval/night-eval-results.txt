WHAT EACH PHASE FIXED
══════════════════════════════════════════════════════════════════════════════
Baseline -> Phase 1 (write path)
  addMeal / replaceMeal / addPerformedTask own the day's lists and totals; the
  LOGGED SO FAR block is re-read every turn. Lunch stopped being wiped and the
  totals stopped drifting. Duplicates dropped but did not stop.

Phase 1 -> final (conversation + the Phase 1 findings)
  One Phase 1 run answered "skipped breakfast today" by re-saving the previous
  turn's dinner and ₹50 — both listed in LOGGED SO FAR — and logging a deck
  review the user had only mentioned as a plan. Two fixes:
    - code: Breakfast/Lunch/Dinner once a day, a repeat reported not added
    - prompt: save what is new in the LATEST message; never save what was only
      planned
  Plus the generated opener and the conversational procedure.
